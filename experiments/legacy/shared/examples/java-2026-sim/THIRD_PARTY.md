# Sources and dependency boundaries

- Official [v2026.2.1 Java template](https://raw.githubusercontent.com/wpilibsuite/vscode-wpilib/v2026.2.1/vscode-wpilib/resources/gradle/java/build.gradle): BSD-3-Clause, full notice in licenses/WPILib-template-BSD.txt. This example removes deployment configuration and supplies original model code.
- [WPILib v2026.2.1](https://github.com/wpilibsuite/allwpilib/tree/v2026.2.1): BSD-3-Clause; API dependencies are downloaded at build time. Full notice in licenses/WPILib-BSD.txt.
- [GradleRIO v2026.2.1](https://github.com/wpilibsuite/GradleRIO/tree/v2026.2.1): MIT; build plugin downloaded at build time. Notice in licenses/GradleRIO-MIT.txt.
- [Gradle 8.11](https://github.com/gradle/gradle/tree/v8.11.0): Apache-2.0 wrapper; license in licenses/Gradle-Apache-2.0.txt and notice in licenses/Gradle-NOTICE.txt. Wrapper generated by that distribution. Gradle distribution itself is not bundled.
- [JUnit 5.10.1](https://github.com/junit-team/junit5/tree/r5.10.1): EPL-2.0; fetched for tests, not bundled in source package.

Only wrapper infrastructure is bundled as a binary. Runtime/test dependencies are fetched from their official build repositories and are not repackaged into a distributable fat JAR. Transitive/native artifacts retain their own licenses. The resolved dependency report is evidence of what was used, not a blanket redistribution clearance for every build output. Complete binary redistribution review remains required before sharing compiled artifacts.
