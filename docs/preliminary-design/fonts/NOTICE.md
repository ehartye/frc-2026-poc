# Review theme fonts

Latin subsets of Barlow Condensed (600, 700) and Source Sans 3 (400, 600) in WOFF2, byte for byte as distributed in the Fontsource 5.2.5 packages built from the Google Fonts releases (`https://cdn.jsdelivr.net/npm/@fontsource/barlow-condensed@5.2.5/files/` and `.../@fontsource/source-sans-3@5.2.5/files/`). Each font is licensed under the SIL Open Font License 1.1. The copyright notices and license texts, from the Google Fonts repository, are in `OFL-BarlowCondensed.txt` and `OFL-SourceSans3.txt`; keep them with any copy of the fonts. Source Sans 3 carries the Reserved Font Name "Source", so do not modify these files under that name. `fonts.css` declares the faces. Pages that link it fall back to system fonts when the directory is absent.
